Stock Jokes

One joke per ticker. Every step is an x402 micro-payment in USDC on Base: StockTwits for the chatter, Ceramic for the news, Cloudflare AI Gateway for the punchline and for the agent's own turns.

The coupon code is optional. Without one you'll get instructions for your agent to pay 0.10 USDC with x402 instead.

  3. 2. Ceramic news search (x402)
  4. 3. Joke from AI Gateway (x402)
  5. Agent finished
    Each model turn is its own x402 payment to AI Gateway.
